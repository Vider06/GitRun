# Workflows

Reusable GitHub Actions workflow building blocks maintained by GitRun.

This is intentionally not a second copy of complete application workflows. Prefer focused building blocks for cache restore, cache save, cleanup, diagnostics, and related concerns.

Categories:
- GitRun-Dependent/ — may require GitRun APIs, GitDockRun, or other GitRun capabilities.
- GitRun-Independent/ — must work on standard GitHub Actions without GitRun.
