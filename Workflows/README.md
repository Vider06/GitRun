# Workflows

Reusable workflow content maintained by GitRun Premade.

Split into GitRun-Dependent and GitRun-Independent workflows.

## GitRun-Dependent routing

`GitRun-Dependent/kitty-dispatch-plan.yml` provides an opt-in Kitty dispatch plan with explicit GitHub fallback outputs; `kitty-dispatch-example.yml` demonstrates dynamic `runs-on` selection. Read the dependent-workflows README for required settings, GSR authorization, the `gitrun-control` runner label, and the control-runner availability limitation.
