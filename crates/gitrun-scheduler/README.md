# `gitrun-scheduler`

GitRun's runtime control plane. It reconciles GitHub jobs and runner pools, creates/removes/restarts runner containers, performs recovery, applies Logic Containers routing, resolves VM backends and runs GitHub/update services.

Kitty is an optional add-on supplied by `gitrun-smart-scheduler`. It is disabled unless `/var/lib/gitrun/kitty/settings.json` is present and valid with `enabled: true`; shadow mode is the default. It observes bounded aggregate queue/runner/resource snapshots and may only raise the effective runner floor within operator and global bounds after its forecasts have demonstrated quality. Kitty errors never abort deterministic reconciliation. PR #83's source HEAD passed runtime-contract, reconciliation, VM-resolution and privileged GitDockRun namespace checks. The complete authorized API disconnect request, live provisioning on real hypervisors and migration of every custom/pre-existing runner image are not covered end to end.
