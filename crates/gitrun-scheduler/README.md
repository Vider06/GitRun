# `gitrun-scheduler`

GitRun's runtime control plane. It reconciles GitHub jobs and runner pools, creates/removes/restarts runner containers, performs recovery, applies Logic Containers routing, resolves VM backends and runs GitHub/update services.

Kitty is an optional add-on supplied by `gitrun-smart-scheduler`. A missing settings file disables it; a valid `enabled: true` setting permits model collection and forecasting, while predictive capacity changes require separate opt-in and shadow mode explicitly disabled. High-resolution samples are limited to seven days, while older history is compacted into bounded week/month/year/lifetime summaries; see the [Kitty README](../gitrun-smart-scheduler/README.md). Kitty observes bounded aggregate queue/runner/resource snapshots and may only raise the effective runner floor within operator and global bounds after forecast evaluation. Kitty errors never abort deterministic reconciliation. PR #83's source-head runtime-contract, reconciliation, VM-resolution and privileged GitDockRun namespace checks are historical 1.5.0 evidence. The complete authorized API disconnect request, live provisioning on real hypervisors and migration of every custom/pre-existing runner image are not covered end to end. PR #103 also added guarded legacy runtime/systemd repair; see the [1.5.1 release notes](../../docs/v1.5.1-release-notes.md) and [historical status report](../../docs/v1.5.0-refactor-status.md).
