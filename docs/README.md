# `docs`

Project architecture and operator documentation for **GitRun 1.4.4**.

The directory covers security enforcement, Rust runtime architecture, Git*Run APIs, IPC/socket behavior and VM-backed runners. The security documentation reflects the 1.4.4 hardening baseline, including authoritative workflow identity, exact Dock bindings, runner cache isolation, dedicated Docker networking, resource-pressure backpressure, VM endpoint health verification and signed release manifests.
