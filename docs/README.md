# `docs`

Project architecture and operator documentation for **GitRun 1.3.0**.

The directory covers security enforcement, Rust runtime architecture, Git*Run APIs, IPC/socket behavior and VM-backed runners. The security documentation reflects the 1.3.0 hardening baseline, including authoritative workflow identity, exact Dock bindings, runner cache isolation, dedicated Docker networking, resource-pressure backpressure, VM endpoint health verification and signed release manifests.
