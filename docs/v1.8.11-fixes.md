# GitRun 1.8.11 source-line notes

This document records the source changes grouped into the 1.8.11 patch line. It does not assert that a signed or installable 1.8.11 release has been published; check [GitHub Releases](https://github.com/Vider06/GitRun/releases).

## Main Library restore timeout

- Remove the explicit `TimeoutStartSec=0` setting from the transient `Type=oneshot` restore unit.
- Let systemd's default oneshot behavior apply: no start timeout is imposed by default. On supported systemd versions, zero can represent an immediate timeout, matching the observed unit result of `timeout` and termination with `SIGTERM`.
- Keep the existing sandbox constraints and the writable path limited to `/usr/share/gitrun/library`.
- Add a regression test for the properties passed to the transient restore unit.

## Workflow API socket path recovery

- Inspect the existing `GITRUN_API_SOCKET` path without following symlinks.
- Remove a Unix socket only if a connection is refused or the path disappears, indicating a stale socket.
- Remove an empty directory at the expected socket path to recover from the observed `/run/gitrun/api.sock: Is a directory` failure.
- Refuse to delete active sockets, symlinks, regular files, or non-empty directories; report a specific actionable error instead.
- Add regression coverage for active and stale sockets, empty and non-empty directories, regular files, and symbolic links.

## Logs clipboard feedback

- Keep the `c` shortcut and bounded OSC 52 clipboard request for the complete loaded Logs output.
- Render Logs status on a dedicated footer line instead of appending it after navigation controls, where it could be clipped on narrow SSH terminals.
- Make clear that sending OSC 52 is not confirmation that the terminal/SSH/tmux client changed the clipboard.
- Bump `gitrun-cli` from 0.13.10 to 0.13.11 and synchronize `Cargo.lock`.

## Version alignment

The source/product target is `1.8.11` in `version.txt`. Only crates with runtime source changes receive patch bumps: `gitrun-scheduler` 0.11.6 → 0.11.7 and `gitrun-recovery` 0.6.12 → 0.6.13. `Cargo.lock` and current-source Markdown markers are synchronized.

## Verification boundary

CI must validate the Rust changes, formatting and regression tests. On MainNode, retry **Restore Main Library** and confirm either a successful signed restore or a specific error from the transient unit. Also restart GitRun and verify that `/run/gitrun/api.sock` becomes a Unix socket and the scheduler remains active. A merged PR or passing CI alone does not establish that the installed host has recovered.
