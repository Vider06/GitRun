# GitRun 1.8.12 source-line notes

This document records the source changes grouped into the 1.8.12 patch line. It does not assert that a signed or installable 1.8.12 release has been published; check [GitHub Releases](https://github.com/Vider06/GitRun/releases).

## Logs clipboard delivery

- Try the operating system's native clipboard helper first when a local desktop session is available: wl-copy on Wayland, xclip or xsel on X11, pbcopy on local macOS, and clip.exe on Windows.
- Use the OSC 52 terminal clipboard sequence when no native helper succeeds, preserving the 64 KiB maximum and copying the newest portion for that remote-terminal path.
- When running inside tmux, wrap OSC 52 in the tmux DCS passthrough sequence. Tmux must be configured with allow-passthrough on, and the outer terminal must permit clipboard writes.
- Report “Copied logs to system clipboard” only after a native helper reports success. The OSC 52 path reports that the request was sent, not that the terminal accepted it.
- Keep the Logs feedback on a dedicated footer line and report when a native clipboard helper could not be used.

## Version alignment

The source/product target is 1.8.12 in version.txt. Only the changed gitrun-cli crate receives a patch bump, from 0.13.11 to 0.13.12. Cargo.lock and current-source Markdown markers are synchronized.

## Verification boundary

CI must validate formatting, the tmux passthrough encoding test, clipboard status text and the CLI build. Test the native helper path in a Linux desktop session and OSC 52 forwarding in the actual SSH/tmux terminal before claiming the host clipboard has been updated.
