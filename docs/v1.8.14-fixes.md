# GitRun 1.8.14 source-line notes

This document describes the source target recorded in `version.txt`. It does not claim that a signed release artifact has been published.

## Logs clipboard and export

- Keep the Logs `c` action responsive by placing a two-second deadline on native clipboard commands.
- Provide a local Windows helper using `clip.exe` and a Windows Save As dialog that opens the saved file in Notepad.
- Provide a Linux helper that tries `wl-copy`, `xclip` and `xsel`, then uses a native Save As dialog when a desktop session is available. The saved file opens with the system's default text editor; on a headless Linux session it is saved under `~/Downloads`.
- Send the complete loaded Logs payload over an authenticated loopback-only SSH forward when a local helper is used. A successful native clipboard operation is acknowledged; a failed copy enters the file-save fallback.
- Keep OSC 52 as the best-effort path for users who open a plain SSH session directly. GitRun waits briefly and creates a private remote `.txt` file, with receive instructions for both Windows and Linux.
- Transfer the one-use helper token via SSH stdin to a remote owner-only file instead of placing it in process arguments. The helper protocol limits log transfer size and uses timeouts for clipboard and save responses.

## GSR bootstrap

- Start the runner entrypoint with the retained, original Bash binary so it can create the protected runtime GSR policy before the wrapped shell agent loads it.
- Apply the same startup order to the Minimum and Workbench profiles and normalize the older immutable Workbench Dockerfile used by setup.
