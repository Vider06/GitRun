# GitRun 1.8.16 source-line notes

This document records the source target in `version.txt`. It does not claim that a signed release artifact has been published.

## GTUU permanent-runner recovery

- Add `gitrun gtuu` with a read-only image/container check, repository-scoped reconciliation, forced local runner-image rebuilding and forced replacement of permanent runners.
- Validate the build fingerprint, expected entrypoint and runtime GSR policy bootstrap before promoting a rebuilt image. Failed builds or validation preserve the prior image tag and existing containers.
- Keep busy runners untouched. Do not remove the old runner until its replacement reports online; retain failed replacements for diagnosis.
- Keep registry-qualified images on the signed-manifest and digest-verification route rather than forcing a local rebuild.
- For system installations, allow `gitrun gtuu` to request administrator authorization itself when the shell is not elevated. An already elevated shell should not trigger another sudo prompt.
- Make `gitrun update --only-containers` delegate through sudo when needed instead of failing while reading protected configuration.

- Bump `gitrun-cli` from `0.13.15` to `0.13.16`, `gitrun-scheduler` from `0.11.9` to `0.11.10`, and `gitrun-setup` from `0.9.11` to `0.9.12`.
