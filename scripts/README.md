# `scripts`

Installation, release-build and verification scripts for Linux, macOS and Windows. Scripts are operational tooling rather than part of the Rust runtime. Check installer and release behavior against the current source/product version in `version.txt`. The 1.7.0 Kitty queue-evaluation work is documented in [the Smart Scheduler guide](../docs/SMART_SCHEDULER.md); the 1.6.2 dashboard settings recovery and earlier legacy runtime migration remain historical records in [the consolidated release history](../docs/RELEASE_HISTORY.md). Historical verification limits are summarized in [release history](../docs/RELEASE_HISTORY.md); they do not validate a new installer or release commit.
