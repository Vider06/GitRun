# `scripts`

Installation, release-build and verification scripts for Linux, macOS and Windows. Scripts are operational tooling rather than part of the Rust runtime. Check installer and release behavior against the current source/product version in `version.txt`. The 1.6.2 dashboard settings recovery is documented in [the current fixes](../docs/v1.6.2-fixes.md); the earlier legacy runtime migration is recorded in [the 1.5.1 recovery notes](../docs/v1.5.1-release-notes.md). Do not treat the older 1.5.0 audit results as validation of a new installer or release commit.
