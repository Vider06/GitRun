# `scripts`

Installation, release-build and verification scripts for Linux, macOS and Windows. Scripts are operational tooling rather than part of the Rust runtime. Check installer and release behavior against the current source/product version in `version.txt`. The 1.6.2 dashboard settings recovery is documented in [the current fixes](../docs/v1.6.2-fixes.md); the earlier legacy runtime migration is recorded in [the consolidated release history](../docs/RELEASE_HISTORY.md). Historical verification limits are summarized in [release history](../docs/RELEASE_HISTORY.md); they do not validate a new installer or release commit.
